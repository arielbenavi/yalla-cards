# Handoff 2026-11-05: state of yalla-cards and what comes next

Written for whoever continues from here, a person or another assistant such as ChatGPT. It covers the work since the beginning of November. Read [CLAUDE.md](../CLAUDE.md) and [README.md](../README.md) first: they hold the rules.

## Rules that do not change
- **Answer in Hebrew.** The user is Ariel. The app is personal: one user, one admin.
- **Reversible, additive changes only.** A new feature may read FSRS state (`card_srs`, `review_log`) but never writes it. The one exception is the `card_srs` row of a new card (`direction: "he_to_ar"`).
- **Migrations:** write a new file `supabase/migrations/00XX_*.sql`, then run `npx tsx scripts/migrate.ts`. Never ask Ariel to run SQL. The last migration is `0033`.
- **Tests:** a change to review, inbox or recordings needs `npx playwright test` to pass in full. Never skip a test.
- **Node 20 for scripts:**
  ```bash
  export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 20
  ```
  Scripts create the Supabase client with `{auth:{persistSession:false}, realtime:{transport: class {} as any}}` and load `config({path:".env.local"})`.
- **Pushing:** `git push` runs `next build` in a pre-push hook. Vercel deploys from main.
- **Nikud:**
  - Every ב takes a dagesh. `fixBet` in `lib/word-lookup.ts` adds it.
  - Geresh is written as a plain apostrophe `'`.
  - Emphatic letters: ض → צ', ص → צ, ظ → ט'. ق in Palestinian is mostly א.
  - Latin pronunciation in Ariel's notes decides the pointing, but it is never stored as a card note.
  - When reading text from an image, use `.claude/skills/reading-nikud-from-images/SKILL.md`.
- **Content:**
  - chatifai, the course bot that checks nikud, has been down. Everything goes in with `chatifai_verified=false`.
  - Never copy song lyrics from the web.
- **Ideas:** every idea Ariel mentions goes into the `notes` table with tag `idea`. Open notes: `SELECT id, body, tag FROM notes WHERE status='open'`.
